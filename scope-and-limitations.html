Hosted inventory v1 scope & limitations

This page is the public boundary for Stocket hosted inventory v1. The release is being prepared for a small invited Design Partner cohort and is not generally available.

Included

Focused inventory capabilities

  • Products and categories
  • Locations with nested storage areas
  • Exact lot-level inventory balances
  • Adjustments, transfers, and compensating corrections
  • Human-reviewed assisted Smart Import
  • Tenant users, roles, settings, and audit views
Not included

Deliberate v1 limits

Orders, clients, suppliers, purchasing, fulfillment, reporting, notifications, billing, public API or MCP access, mobile, remote desktop, offline or PWA behavior, German localization, and high availability are not included.

Removed application and API paths return the standard not-found response. There is no public self-registration.

Inventory safety

How stock remains explainable

Exact balances

Each balance holds one stock lot in one leaf area. Base-unit quantities are exact, never silently rounded, and never negative.

Immutable history

Completed history is not edited. Mistakes are resolved with a compensating correction that preserves what happened.

One operation path

Manual work and approved import rows follow the same stock-operation rules. Established stock is never overwritten automatically.

Operational boundary

Single-host release with proven recovery

The release may use one application host. Before approval, recovery evidence must prove a recovery point of at most one hour and recovery within four hours. Until every release criterion has concrete evidence, hosted v1 remains in preparation.
